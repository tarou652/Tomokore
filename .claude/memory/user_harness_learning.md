ユーザーはトモコレアプリ開発と**並行して**Claude Codeのハーネスエンジニアリングを体験・学習している。

**学習スタイル**: 実際にCLAUDE.mdやsettings.jsonを作成しながら体験する実践型。

**最終ゴール**: ハーネスエンジニアリングの体験をもとに**記事を作成する**。
- メモリシステム（MEMORY.md + メモリファイル）はその記事執筆の素材として活用予定。

**How to apply:**
- ハーネスの概念を説明するときは「なぜそう設計されているか」の背景も添える
- 記事ネタになりそうな「気づき」「ハマりポイント」「AHA moment」は積極的にメモリに記録する
- 設定ファイルを作る際は、その設定が何をしているか学習者目線で解説する
